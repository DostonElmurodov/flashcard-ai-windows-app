+# Provider expenditure guard
+
+The guard is disabled in example configuration. No production money amounts,
+commercial D2 quota, or automatic monetary reset has been approved. Enabling it
+requires all positive limits below and a reviewed price profile. Missing,
+invalid, disabled or unsupported configuration denies new provider traffic with
+503. Test mode cannot bypass this boundary. Saved reading/review is unaffected;
+a valid service-cache hit creates no provider reservation.
+
+## Accounting and authorization boundary
+
+Each actual OpenAI/Gemini attempt has a new server-generated ID and an atomic
+PostgreSQL reservation before HTTP. Fallback needs another reservation. A short
+transaction advisory lock serializes global and cohort accounting across API
+replicas; it is released before HTTP. Amounts are integer micro-USD (1 USD =
+1,000,000 micro-USD). The global allowance covers both aggregate pools: `guest`
+and `account`. These are cumulative allowances, with no UTC-day/month reset and
+no identity/clock-based forgiveness. Budget changes do not erase recorded spend.
+
+The accepted authorization filters grant the scoped context after authentication,
+request proof and applicable entitlement/quota gates. Development test mode grants
+it only after authentication/proof. The account reference comes from validated
+account authentication; the guest reference comes from the authenticated device
+key. Only a SHA-256 reference is stored in this ledger; it is still pseudonymous
+internal data. Neither that key nor a mutable device UUID proves immutable
+anonymous purchase ownership. Tasks2/3/6 must integrate the final anonymous
+owner/recovery and shared-owner operation quota contracts. This task does not
+implement those schemas, key-rotation allowance sharing, or desktop linking.
+
+Only consistent usage matching the reserved model and requested standard tier
+releases the verified difference. The settled amount remains a **conservative
+usage-based cost ceiling**, not the provider invoice. OpenAI output already
+includes reasoning; cache reads/writes are alternatives to ordinary input.
+Gemini candidates plus thoughts form output; cached input is a subset of prompt
+tokens. Missing required usage components, mismatched model/tier, negative or
+inconsistent values, overflow, and usage exceeding caps retain the full reserve.
+Settlement is idempotent and rates/caps are frozen on each reservation.
+
+An HTTP error, malformed response, cancellation, timeout, failed settlement or
+process crash is not evidence of zero cost. Unknown outcomes retain both money
+and their persistent concurrency slots. There is no TTL release. This can stop
+new AI calls after enough unknown attempts; this availability cost is deliberate.
+Known complete usage settlement releases the slot, but never the accounted cost.
+
+## Reviewed profile and arithmetic
+
+The only live-capable profile identifier is `2026-09-27-model-ceilings-v1`.
+All four operations (`analyze-word`, `word-detail`, `review-translation`,
+`extract-words`) use the same conservative ceilings; the word-detail primary/
+secondary bundle is one operation, not multi-word fan-out. Images use a full
+model input ceiling, not an invented byte-to-token conversion. Only text and
+supported image MIME inputs are submitted. Tools, external files, audio, video,
+grounding, persistent cache creation and additional candidates are not requested.
+
+Official OpenAI model/pricing documentation reviewed 2026-09-27:
+[GPT-6 Luna](https://developers.openai.com/api/docs/models/gpt-6-luna),
+[Responses](https://developers.openai.com/api/reference/cli/resources/responses/methods/create),
+[cache usage](https://developers.openai.com/api/docs/guides/prompt-caching#monitor-cache-performance).
+Luna's documented context ceiling is 1,050,000 tokens (the docs connector also
+states a lower maximum input; using the full context is conservative). Reserve
+input at $0.125/M × 2 long-context × 1.10 regional × 2 fast = $0.55/M.
+Output envelope is $0.50/M × 1.5 long-context × 1.10 regional × 2 fast = $1.65/M.
+The ordinary/read/write input envelopes are 440/44/550 nano-USD per token;
+output is 1650. Requests explicitly select `service_tier=default` and reasoning
+`none`; settlement requires the returned tier `default` and model `gpt-6-luna`.
+This retains extra protection even though standard processing is requested.
+
+Official Gemini documentation reviewed 2026-09-27:
+[model limits](https://ai.google.dev/gemini-api/docs/models/gemini-2.5-flash),
+[pricing](https://ai.google.dev/gemini-api/docs/pricing#gemini-2.5-flash),
+[request/usage schema](https://ai.google.dev/api/generate-content).
+The input ceiling is 1,048,576 tokens. Priority text/image rates conservatively
+cover the requested standard tier: ordinary/cache input $0.54/$0.054 per million,
+output including thoughts $4.50/M (540/54/4500 nano-USD per token). No explicit
+cache creation/storage is used. Requests select `serviceTier=standard`, one
+candidate, `thinkingBudget=0`, and a positive output cap. Settlement requires
+exact `modelVersion=gemini-2.5-flash` and `usageMetadata.serviceTier=standard`;
+unrecognized/missing versions or usage components retain the reserve.
+
+Reservation = ceil((full input ceiling × maximum input nano-rate + configured
+output cap × output nano-rate) / 1000). Validated settlement applies the frozen
+rates to disjoint input components and normalized output, also rounding up.
+All arithmetic is checked. With a **synthetic test-only** output cap of 512,
+the reservations are 578,345 micro-USD (OpenAI) and 568,536 (Gemini). These are
+technical calculations, not approved allowances or expected invoice amounts.
+
+## Configuration and transport constraints
+
+Required `AiSpend` settings: `Enabled`, `GlobalMicroUsd`, `GuestMicroUsd`,
+`AccountMicroUsd`, `MaxConcurrentAttempts`, `PriceProfile`, `MaxPromptBytes`,
+`MaxImageBytes`, `MaxOutputTokens`, `MaxResponseBytes`, `DeadlineMilliseconds`.
+All numeric limits must be positive. Implemented maximum configuration bounds:
+64,000 UTF-8 prompt bytes, 20,000,000 image bytes, 65,536 output tokens,
+4,000,000 response bytes and 60,000 ms. These are technical upper bounds,
+not defaults or approved product quotas. Select smaller reviewed values as needed.
+Input is checked before Base64/JSON serialization; these caps also bound serialized
+request size. Text routes may have smaller upstream request-body limits.
+
+The named client uses exact HTTP/1.1, non-null POST content, no Expect-Continue,
+redirects, proxy, cookies, credentials, decompression or retry handlers. Header
+values are explicitly redacted. Response headers are bounded; `ResponseHeadersRead`
+plus incremental byte counting bounds the body with or without Content-Length.
+A linked deadline covers reservation, send, headers and body, independent of
+HttpClient's header-only timeout semantics. Automatic response draining is disabled.
+Settlement then has a separate bounded five-second database deadline. Cancellation is terminal. Provider
+401/402/403/429 and local authorization/quota/spend denials never trigger fallback
+or an outage email. Provider failures with unknown cost remain reserved.
+
+Transport evidence is local loopback against the actual Program named-client
+registration on .NET 10.0.12: posted-body disconnect, reused connection disconnect,
+307 redirect, oversized chunked body and headers-first body stall. Source basis:
+[HTTP/1 connection](https://raw.githubusercontent.com/dotnet/runtime/v10.0.12/src/libraries/System.Net.Http/src/System/Net/Http/SocketsHttpHandler/HttpConnection.cs)
+and [pool retries](https://raw.githubusercontent.com/dotnet/runtime/v10.0.12/src/libraries/System.Net.Http/src/System/Net/Http/SocketsHttpHandler/ConnectionPool/HttpConnectionPool.cs).
+Revalidate on runtime, handler, endpoint, model or pricing changes. The floating
+deployment image is not proof of the tested runtime. There were no live provider
+probes; provider adherence to documented token limits/rates remains an assumption.
+Other services sharing the provider keys are outside this ledger and must be
+budgeted independently. Provider dashboard budgets are not claimed as hard caps.
+
+## Internal monitoring and reconciliation
+
+`OwlAI.ProviderSpend` emits fixed-category event counters; structured logs record
+allowed/denied operations, reservations, provider attempts, fallback, 80% threshold,
+usage ceilings, retained outcomes and settlement failures. Logs do not include
+raw prompts, images, credentials, JWT/JWS or arbitrary provider exception text.
+The 100% allowance is enforced before the next attempt. Alerts in local tests use
+fake sinks only; this work sends no external notification.
+
+Before enabling or after an outage, inspect aggregate `ai_spend_buckets` amounts
+and pending counts and `ai_spend_reservations` grouped by provider/cohort and
+settled/pending state. Pending age is diagnostic, never authority to release.
+If the pending slots stop traffic, disable new calls on **all** replicas using
+`AiSpend__Enabled=false`. Preserve the ledger, isolate provider logs and reconcile
+each attempt against independently verified provider outcome/usage or proof it
+was never sent. Never clear rows, reset buckets, change identity, or wait for a
+TTL as a recovery shortcut. Any repair/reset/allowance increase needs a separate
+approved, reviewed and tested procedure; no live reconciliation/reset action is
+implemented here. Check effective configuration consistency across replicas.
+
+The migration only adds spend tables/index/check constraints. Local tests cover
+upgrading the preceding schema through actual API startup with an existing row,
+replica contention, restart retention, repeated settlement, all current routes,
+normal and test-mode grants, cache hits, and fake fallback. They do not establish
+production readiness, immutable anonymous ownership, live key usage, invoice
+accuracy, or approved financial policy.

+    public static SocketsHttpHandler CreateHandler() => new()

+        AllowAutoRedirect = false, UseProxy = false, Credentials = null, PreAuthenticate = false,
+        AutomaticDecompression = DecompressionMethods.None, UseCookies = false,
+        ConnectTimeout = TimeSpan.FromSeconds(10), MaxResponseHeadersLength = 32, MaxResponseDrainSize = 0

+    public async Task<JsonDocument> SendAsync(AiCostProfile profile, string operation, HttpRequestMessage request, CancellationToken ct)
+    {
+        ct.ThrowIfCancellationRequested();
+        var subject = context.Subject ?? throw new AiSpendDeniedException("missing_context");
+        if (request.Method != HttpMethod.Post || request.Content == null) throw new AiSpendDeniedException("transport_shape");
+        // Pinned .NET 10 HTTP/1 path: non-null POST, no Expect/redirect/proxy/auth negotiation.
+        // Do not relax this without revalidating the loopback retry tests and runtime source.
+        request.Version = HttpVersion.Version11;
+        request.VersionPolicy = HttpVersionPolicy.RequestVersionExact;
+        request.Headers.ExpectContinue = false;
+        using var deadline = CancellationTokenSource.CreateLinkedTokenSource(ct);
+        deadline.CancelAfter(profile.DeadlineMilliseconds);
+        SpendReservation? reservation;
+        try
+        {
+            reservation = await guard.TryReserveAsync(new(Guid.NewGuid(), subject, operation, profile, profile.ReservationMicroUsd), deadline.Token);
+        }
+        catch (OperationCanceledException) { throw; }
+        catch (Exception) { throw new AiSpendDeniedException("ledger_unavailable"); }
+        if (reservation == null) throw new AiSpendDeniedException("budget_or_concurrency");

+        try
+        {
+            deadline.Token.ThrowIfCancellationRequested();
+            events.Record("provider_attempt", profile.Provider);
+            using var response = await clients.CreateClient(ClientName).SendAsync(request, HttpCompletionOption.ResponseHeadersRead, deadline.Token);
+            if (!response.IsSuccessStatusCode)
+                throw new AiProviderException(profile.Provider, "Provider request failed.", (int)response.StatusCode);
+            if (response.Content.Headers.ContentLength > profile.MaxResponseBytes) throw new AiProviderException(profile.Provider, "Provider response exceeds limit.");
+            await using var stream = await response.Content.ReadAsStreamAsync(deadline.Token);
+            using var buffer = new MemoryStream();
+            var block = new byte[8192];
+            while (true)

+                var count = await stream.ReadAsync(block.AsMemory(0, Math.Min(block.Length, profile.MaxResponseBytes - (int)buffer.Length + 1)), deadline.Token);
+                if (count == 0) break;

+            }

+            using var settlementDeadline = new CancellationTokenSource(TimeSpan.FromSeconds(5));

+        }

+public sealed class AiSpendGuard(AppDbContext db, IConfiguration config, IAiSpendEvents events) : IAiSpendGuard
+{
+    public async Task<SpendReservation?> TryReserveAsync(AiAttempt attempt, CancellationToken ct)
+    {
+        ct.ThrowIfCancellationRequested();
+        if (!bool.TryParse(config["AiSpend:Enabled"], out var enabled) || !enabled
+            || !Positive("GlobalMicroUsd", out var global) || !Positive("GuestMicroUsd", out var guest)
+            || !Positive("AccountMicroUsd", out var account) || !Positive("MaxConcurrentAttempts", out var concurrent)

+            || string.IsNullOrWhiteSpace(attempt.Subject.Reference) || attempt.AttemptId == Guid.Empty
+            || !AiCostProfile.IsOperation(attempt.Operation)) return Denied("configuration");
+        try
+        {
+            if (attempt.UpperBoundMicroUsd <= 0 || attempt.UpperBoundMicroUsd != attempt.Profile.ReservationMicroUsd)
+                return Denied("cost_bound");
+        }
+        catch (OverflowException) { return Denied("cost_bound"); }
+
+        // One short transaction lock orders reservation and settlement on every replica.
+        // Never hold this lock while awaiting an external provider.
+        await using var tx = await db.Database.BeginTransactionAsync(ct);
+        await LockAsync(ct);
+        if (await db.AiSpendReservations.AsNoTracking().AnyAsync(x => x.Id == attempt.AttemptId, ct)) return Denied("duplicate_attempt");
+        var cohort = attempt.Subject.Kind;
+        var scopes = new[] { (Id: "global", Limit: global), (Id: cohort, Limit: cohort == "guest" ? guest : account) };
+        var buckets = new List<AiSpendBucketEntity>();
+        foreach (var scope in scopes)
+        {
+            var bucket = await db.AiSpendBuckets.AsNoTracking().SingleOrDefaultAsync(x => x.Id == scope.Id, ct)
+                ?? new AiSpendBucketEntity { Id = scope.Id };
+            if (bucket.ChargedMicroUsd < 0 || bucket.PendingAttempts < 0
+                || attempt.UpperBoundMicroUsd > scope.Limit || bucket.ChargedMicroUsd > scope.Limit - attempt.UpperBoundMicroUsd)
+                return Denied(scope.Id);
+            if (bucket.PendingAttempts >= concurrent) return Denied("concurrency");
+            buckets.Add(bucket);
+        }
+        foreach (var bucket in buckets)
+        {
+            var amount = checked(bucket.ChargedMicroUsd + attempt.UpperBoundMicroUsd);
+            var pending = checked(bucket.PendingAttempts + 1);
+            await db.Database.ExecuteSqlInterpolatedAsync($"""
+                INSERT INTO ai_spend_buckets ("Id", "ChargedMicroUsd", "PendingAttempts") VALUES ({bucket.Id}, {amount}, {pending})
+                ON CONFLICT ("Id") DO UPDATE SET "ChargedMicroUsd" = EXCLUDED."ChargedMicroUsd", "PendingAttempts" = EXCLUDED."PendingAttempts"
+                """, ct);
+        }
+        var p = attempt.Profile;
+        var row = new AiSpendReservationEntity
+        {
+            Id = attempt.AttemptId, Cohort = cohort, SubjectHash = Convert.ToHexString(SHA256.HashData(Encoding.UTF8.GetBytes(cohort + ":" + attempt.Subject.Reference))),
+            Operation = attempt.Operation, Provider = p.Provider, Model = p.Model, Profile = p.Id,
+            ReservedMicroUsd = attempt.UpperBoundMicroUsd, ChargedMicroUsd = attempt.UpperBoundMicroUsd,
+            MaxInputTokens = p.MaxInputTokens, MaxOutputTokens = p.MaxOutputTokens,
+            InputRate = p.InputRate, CacheRate = p.CacheRate, CacheWriteRate = p.CacheWriteRate, OutputRate = p.OutputRate, CreatedAt = DateTime.UtcNow
+        };

+        finally { db.Entry(row).State = EntityState.Detached; }

+        foreach (var scope in scopes)
+        {

+            // decimal avoids overflow when comparing large integer-micro-USD allowances.
+            if ((decimal)bucket.ChargedMicroUsd + attempt.UpperBoundMicroUsd >= (decimal)scope.Limit * 0.8m)
+                events.Record("threshold_80", scope.Id);
+        }
+        return new(row.Id, row.ReservedMicroUsd);
+    }
+
+    public async Task CompleteAsync(Guid reservationId, AiAttemptUsage? usage, CancellationToken ct)
+    {
+        await using var tx = await db.Database.BeginTransactionAsync(ct);
+        await LockAsync(ct);
+        var row = await db.AiSpendReservations.AsNoTracking().SingleOrDefaultAsync(x => x.Id == reservationId, ct);
+        if (row == null || row.SettledAt != null) return;
+        if (!TryCost(row, usage, out var cost)) { events.Record("retained_unknown", row.Cohort, row.ReservedMicroUsd); return; }
+        var released = row.ReservedMicroUsd - cost;
+        var now = DateTime.UtcNow;
+        foreach (var id in new[] { "global", row.Cohort })
+        {
+            var changed = await db.Database.ExecuteSqlInterpolatedAsync($"""
+                UPDATE ai_spend_buckets SET "ChargedMicroUsd" = "ChargedMicroUsd" - {released}, "PendingAttempts" = "PendingAttempts" - 1
+                WHERE "Id" = {id} AND "ChargedMicroUsd" >= {released} AND "PendingAttempts" > 0
+                """, ct);
+            if (changed != 1) throw new AiSpendDeniedException("ledger_inconsistent");
+        }
+        await db.AiSpendReservations.Where(x => x.Id == reservationId).ExecuteUpdateAsync(s => s
+            .SetProperty(x => x.ChargedMicroUsd, cost).SetProperty(x => x.SettledAt, now)
+            .SetProperty(x => x.InputTokens, usage!.Input).SetProperty(x => x.OutputTokens, usage!.Output)
+            .SetProperty(x => x.ReasoningTokens, usage!.Reasoning).SetProperty(x => x.CachedTokens, usage!.Cached)
+            .SetProperty(x => x.CacheWriteTokens, usage!.CacheWrite), ct);
+        await tx.CommitAsync(ct);
+        events.Record("settled_usage_ceiling", row.Cohort, cost);
+    }
+
+    private static bool TryCost(AiSpendReservationEntity row, AiAttemptUsage? u, out long cost)
+    {
+        cost = 0;
+        if (u == null || u.Model != row.Model || u.Tier != (row.Provider == "OpenAI" ? "default" : "standard")
+            || u.Input <= 0 || u.Input > row.MaxInputTokens || u.Output < 0 || u.Output > row.MaxOutputTokens
+            || u.Reasoning < 0 || u.Reasoning > u.Output || u.Cached < 0 || u.CacheWrite < 0
+            || row.InputRate <= 0 || row.CacheRate <= 0 || row.CacheWriteRate <= 0 || row.OutputRate <= 0) return false;
+        try
+        {
+            if (checked(u.Input + u.Output) != u.Total || checked(u.Cached + u.CacheWrite) > u.Input) return false;
+            var nano = checked(checked((u.Input - u.Cached - u.CacheWrite) * row.InputRate)
+                + checked(u.Cached * row.CacheRate) + checked(u.CacheWrite * row.CacheWriteRate) + checked(u.Output * row.OutputRate));
+            cost = checked(nano + 999) / 1000;
+            return cost <= row.ReservedMicroUsd;
+        }
+        catch (OverflowException) { return false; }
+    }

+    private Task LockAsync(CancellationToken ct) => db.Database.ExecuteSqlRawAsync("SELECT pg_advisory_xact_lock(748237195013)", ct);

+    private sealed class Loopback : IDisposable
+    {
+        private readonly TcpListener listener = new(IPAddress.Loopback, 0);
+        private readonly CancellationTokenSource stopped = new();
+        private readonly Task serving;
+        private int submissions, connections;
+        public int Submissions => Volatile.Read(ref submissions);
+        public int Connections => Volatile.Read(ref connections);
+        public string LastHeaders { get; private set; } = "";
+        public string Url { get; }
+        public Loopback(string mode)
+        {
+            listener.Start(); Url = $"http://127.0.0.1:{((IPEndPoint)listener.LocalEndpoint).Port}/";
+            serving = Serve(mode);
+        }
+        private async Task Serve(string mode)
+        {
+            try
+            {
+                while (!stopped.IsCancellationRequested)
+                {
+                    using var socket = await listener.AcceptTcpClientAsync(stopped.Token); Interlocked.Increment(ref connections);
+                    var stream = socket.GetStream();
+                    await ReadPost(stream);
+                    if (mode == "disconnect") continue;
+                    if (mode == "pooled")
+                    {
+                        await Write(stream, "HTTP/1.1 200 OK\r\nContent-Length: 2\r\n\r\n{}");
+                        await ReadPost(stream); continue;
+                    }
+                    if (mode == "redirect") await Write(stream, $"HTTP/1.1 307 Temporary Redirect\r\nLocation: {Url}target\r\nContent-Length: 0\r\nConnection: close\r\n\r\n");
+                    if (mode == "chunked") await Write(stream, "HTTP/1.1 200 OK\r\nTransfer-Encoding: chunked\r\nConnection: close\r\n\r\n200\r\n" + new string('x', 512) + "\r\n0\r\n\r\n");
+                    if (mode == "slow")
+                    {
+                        await Write(stream, "HTTP/1.1 200 OK\r\nTransfer-Encoding: chunked\r\n\r\n");
+                        await Task.Delay(Timeout.Infinite, stopped.Token);
+                    }
+                }
+            }
+            catch (OperationCanceledException) { }
+            catch (IOException) when (stopped.IsCancellationRequested) { }
+            catch (SocketException) when (stopped.IsCancellationRequested) { }
+        }
+        private async Task ReadPost(NetworkStream stream)
+        {
+            using var header = new MemoryStream(); var one = new byte[1];
+            while (header.Length < 32768)
+            {
+                if (await stream.ReadAsync(one, stopped.Token) == 0) throw new IOException("Connection closed before request.");
+                header.WriteByte(one[0]);
+                if (header.Length >= 4 && Encoding.ASCII.GetString(header.GetBuffer(), (int)header.Length - 4, 4) == "\r\n\r\n") break;
+            }
+            LastHeaders = Encoding.ASCII.GetString(header.ToArray());
+            var length = int.Parse(LastHeaders.Split("\r\n").Single(x => x.StartsWith("Content-Length:", StringComparison.OrdinalIgnoreCase)).Split(':')[1]);
+            var body = new byte[length]; await stream.ReadExactlyAsync(body, stopped.Token);
+            Interlocked.Increment(ref submissions);
+        }
+        private Task Write(NetworkStream stream, string content) => stream.WriteAsync(Encoding.ASCII.GetBytes(content), stopped.Token).AsTask();
+        public void Dispose()
+        {
+            stopped.Cancel(); listener.Stop(); serving.GetAwaiter().GetResult(); stopped.Dispose();
+        }
+    }
