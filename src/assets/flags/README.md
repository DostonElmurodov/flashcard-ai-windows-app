Language flags are bundled copies of the `LangFlag_*` PNG assets in the user's
CDLVocab reference project. The reference attributes the original 320px country
flag artwork to [FlagCDN](https://flagcdn.com). The language-to-country mapping is
preserved, including US English, Hong Kong Cantonese, and Brazilian Portuguese.
Bundled images avoid platform-dependent flag emoji rendering on Windows.
